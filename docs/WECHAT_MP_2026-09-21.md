## 交付口径

- 表1：所有时间合格且由配置关键词实际搜到的候选；“是”为明确有效，“否”为明确无关，“待核验”为证据不足，并写具体原因。
- Summary：`total_candidates`、`valid_articles`、`invalid_articles`、`pending_review_articles`，三类数量之和等于总候选数。
- 表3/表5保持按明确有效文章统计，避免未核验候选影响有效发文/互动汇总。
- 表2/表4在公开源无评论时为空表，不虚构评论。
- 每个内容/账号/评论ID保持字符串。原始缺失保留null；v2展示层使用明确文本状态及数值0占位，未取得官方账号ID时使用local_wxacct_*本地关联键。
- canonical URL通过正常公开结果点击、浏览器跳转及公开canonical标记尽力获取，失败保留搜狗链接，不算采集失败。遇到验证仍暂停人工处理，不拼造token、不解密跳转、不请求私有接口。

完成时目录内包含五份CSV、`search_contents.jsonl`、六张工作表的XLSX、`summary.json`、`README.txt`以及：

```text
table5_batch.json
```

五个文件均为JSON数组，采用接口英文键名和顺序；`matched_keywords`为数组，表2/4为空数组。

## POMS上传

上传脚本使用接口指南的 `POST /api/v1/tables/<英文表名>/batch`，依次上传表1—表5；不涉及分类表。
认证头为 `X-API-Key`。服务器地址从本机 `POMS_URL` 读取，API Key从 `POMS_API_KEY` 读取；请按照接口指南在本机设置，勿把实际IP或凭据写入采集交付文件或聊天。
默认无需服务器配置文件；`config/poms.wechat_mp.example.json`仅用于覆盖环境变量名。

Windows入口为 `scripts/upload_wechat_poms_windows.ps1`。指定批次目录，不会自动查找昨日或最新的其他目录。
默认优先读取完整的五份CSV；没有CSV时读取 `search_contents.jsonl`。存在部分CSV则报错；可用 `-Source jsonl` 明确选择JSONL。
CSV按五表导出值转换；JSONL经现有去重、时间/主题规则重建五表。JSONL模式只适用于公开搜索候选记录，表2/4为空。
转换只写五份 `tableN_batch.json` 和 `poms_conversion.json`，不改原CSV/JSONL/XLSX。
转换前会检查五个batch样例中的全部记录键名和顺序、实际数据类型、引用ID及文章时间范围；缺少源文件、范围信息或发现越界数据时停止。
其他日期批次可用 `-BatchDir` 指定；没有 `summary.json` 时需用 `-Config` 提供该批次监测配置，不能借用今日配置处理其他批次。

在仓库根目录先生成并校验五个JSON数组，无需服务器地址或API Key：

```powershell
.\scripts\upload_wechat_poms_windows.ps1 -BatchDir data_submissions/wechat_mp/2026-09-21_wechatmp02 -ConvertOnly
# -DryRun同样执行转换和本地校验，不发网络请求。
.\scripts\upload_wechat_poms_windows.ps1 -BatchDir data_submissions/wechat_mp/2026-09-21_wechatmp02 -DryRun
```

完成真实采集后，在本机输入服务器地址和密钥并上传（密钥输入隐藏）：

```powershell
$env:POMS_URL = Read-Host 'POMS URL from the batch API guide'
$env:POMS_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'POMS API Key' -AsSecureString)).Password
.\scripts\upload_wechat_poms_windows.ps1 -BatchDir data_submissions/wechat_mp/2026-09-21_wechatmp02
```

正式上传会先重新转换源数据，核对HTTP状态及返回数组数量，遇到错误停止，不自动重试。密钥仅从环境变量读取，不进入命令行参数、配置或日志。
本地校验使用已核对的OpenAPI约束和batch样例，不执行上传；服务端将来修改schema时应同步核对。接口按主键更新的行为以服务端指南为准。
采集器从不自动调用上传脚本。本次开发没有向服务器上传数据，不自动commit/push。
