# POMS Demo 手动网络接口批量测试流程

本目录为9张可写表分别准备了至少50条测试数据。本流程由你手动执行；生成数据时没有向服务器发送请求。

## 重要提醒

最后的整表清空会删除对应表中的全部数据，不只删除本批测试数据。确认数据库没有其他同学的重要数据后才能执行清空部分。

## 一、进入测试目录

```bash
cd /Users/anfies/Desktop/project/Public_Opinion_Monitoring_System/batch_test_samples
ls
```

## 二、设置地址和API Key

```bash
export POMS_URL='http://49.233.133.197:8000'
export POMS_API_KEY='替换成服务器.env中的API Key'
curl "$POMS_URL/health"
```

看到 `{"status":"ok"}` 后继续。

## 三、批量写入表1—表5

必须按下面顺序逐条执行：

```bash
curl -X POST "$POMS_URL/api/v1/tables/published_content_basic_information/batch" -H "X-API-Key: $POMS_API_KEY" -H "Content-Type: application/json" --data-binary @01_batch_published_content_basic_information.json

curl -X POST "$POMS_URL/api/v1/tables/comment_basic_information/batch" -H "X-API-Key: $POMS_API_KEY" -H "Content-Type: application/json" --data-binary @02_batch_comment_basic_information.json

curl -X POST "$POMS_URL/api/v1/tables/published_content_interaction_data/batch" -H "X-API-Key: $POMS_API_KEY" -H "Content-Type: application/json" --data-binary @03_batch_published_content_interaction_data.json

curl -X POST "$POMS_URL/api/v1/tables/comment_content_interaction_data/batch" -H "X-API-Key: $POMS_API_KEY" -H "Content-Type: application/json" --data-binary @04_batch_comment_content_interaction_data.json

curl -X POST "$POMS_URL/api/v1/tables/account_information/batch" -H "X-API-Key: $POMS_API_KEY" -H "Content-Type: application/json" --data-binary @05_batch_account_information.json
```

每次返回一个包含50条记录的JSON数组。确认本次成功后再执行下一条。
