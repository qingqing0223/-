# 学生采集数据提交目录

从现在起，学生新采集的数据统一放在本目录，不再使用旧的 `results/` 作为人工数据提交区。

## 目录

- `douyin/`：抖音
- `kuaishou/`：快手
- `bilibili/`：B站
- `weibo/`：微博
- `xiaohongshu/`：小红书
- `tieba/`：百度贴吧
- `zhihu/`：知乎
- `wechat_mp/`：微信公众号

## 提交规范

每位同学在对应平台目录下再建自己的子目录，建议使用：

`YYYY-MM-DD_姓名或节点名/`

例如：

`kuaishou/2026-09-20_ks01/`

可以提交原始 JSONL、CSV、统计结果和必要说明。不要提交 Cookie、账号密码、API Key、浏览器登录态、真实网络 IP 或其他敏感凭据。
